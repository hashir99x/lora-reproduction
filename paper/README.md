# paper.pdf

The original paper PDF is **not included** here, out of respect for
copyright — this project doesn't bundle a full copy of someone else's
published paper.

To add it yourself:

1. Download it from arXiv: https://arxiv.org/abs/2106.09685
2. Save it as `paper/paper.pdf`

A full paraphrased summary of the paper's methodology (the core LoRA
mechanism, initialization scheme, where it's applied, and headline
results) is in `notes/summary.md`, and a term-by-term comparison against
this reproduction's methodology is in the main `README.md`.
